Personal AI Memory OS 便携桌面版

请先完整解压 ZIP，再双击 PersonalAiMemoryOs.exe。请保留整个目录，包括 _internal。
基础资料、笔记、Markdown 同步无需安装 Python、uv 或 Docker。
需要 Windows x64、.NET Framework 4.8 和 Microsoft Edge WebView2 运行环境。
WebView2 官方下载：https://developer.microsoft.com/microsoft-edge/webview2/

首次启动会在 EXE 所在目录创建空数据库、知识目录、个人配置、日志和浏览器缓存。
此目录应可写；请放在自己的用户目录，不要放在 Program Files 或只读介质。
建议配置文件和数据目录保持默认设置。桌面版不会读取其他项目的数据库。

0.8.0 可视化设置：点击工作台左上角“设置”，或桌面菜单“设置 → AI 接口设置”。
在页面填写服务地址、模型、协议及密钥，支持多套配置和高级参数。
密钥不回显；已有密钥留空会保留。保存不调用模型，也不会立即启用当前运行进程。
保存成功且需要重启时会询问“现在重启／稍后”；选择现在重启会等待在途调用正常结束，
再从同一目录重开。稍后保留配置；刷新网页不等于重启。启用真实模型后主动生成会产生供应商费用。
页面只读展示运行、配置和数据位置；RAG设置可维护Embedding多套配置、维度、密钥引用及Qdrant地址。
默认RAG关闭，保存配置不调用模型。Qdrant连接检测只读取服务信息；Embedding试调用需明确确认。
真正开启后会自动索引已保存知识笔记，资料原文和未采纳草稿不直接进入索引。
环境变量托管的设置不能在页面覆盖；Docker 配置由宿主机管理，网页只读。
若提示配置已被修改，先保留自己的输入，再明确选择重新读取；程序不会自动覆盖。

资料库：同标题显示为一组，进入后分别阅读各作者的回答；原始记录保持独立。
标题列表与组内资料均支持每页10/20/50/100条、点击页码与输入页码跳转。
可按标题、资料数量、来源类型、更新时间排序，支持升序/降序与点击表头切换。
排序后再分页；翻页和返回列表保留排序。标题/类型按字符顺序，混合类型组取最前的类型。
固定安装目录：dist/PersonalAiMemoryOs-0.6.6/，保留历史目录名，程序显示版本为 0.8.0。
后续使用相同安装目录，正常退出后由项目升级脚本备份并核验数据库、完整知识目录和配置，
再原地替换程序资源。个人数据、配置、日志、导出和未知文件保留；数据库升级为 0006。
新发行ZIP从干净构建产生，不从有个人数据的目录打包。不要将干净包直接覆盖运行中的安装。
不要覆盖正在运行的旧程序，不要仅替换网页或 EXE；本版需要完整后端与 _internal。

0.8.0 页面：AI分析负责选择资料和提交任务；草稿箱单独浏览、预览和采纳生成结果。
独立Prompt中心管理“笔记解析”和“知识库问答”模板，每类有自己的默认项和修订历史。
所有记录列表统一10/20/50/100条每页、页码和跳转。同标题资料按需展开全文。
资料选择跨页保留，最多20篇；分页显示100条不表示可以一次生成100篇。
支持逐篇生成和合并分析；深度分析预填16384输出tokens、180秒，可改，不改变模型思考模式。
默认完整八阶段知乎观点解析，不联网核验；事实不确定时标记待验证。模板在Prompt中心管理，保存立即生效。
批次进度持久保存；取消只阻止后续调用，当前调用收尾。重启后暂停，不自动重发付费调用。
继续待处理项和重试失败项分别确认。合并草稿采纳后关联全部来源，旧草稿仍兼容。
笔记保存成功（含无修改保存）返回概览首页；失败保留输入。资料保存保持原分页返回逻辑。

数据、配置与备份：
- data/memory.db：SQLite 数据库
- knowledge/：Markdown 知识库，包含用于识别目录的标记文件
- config/：个人模型和 Embedding 配置
- .env：开关、密钥与运行配置；不要将密钥发给他人
- logs/：轮转运行日志
- .cache/：浏览器和运行缓存
备份或移动前请先正常关闭窗口，再复制完整便携目录。

AI 和 RAG 默认关闭。需要自行配置模型服务；语义检索另需可用的 Qdrant。
修改 .env 或 YAML 配置后请退出并重新打开。API 密钥不会随发行包提供。
遇到问题可使用桌面菜单打开日志。关闭过程中有任务时请等待正常退出。
此版本未签名、不含安装器或自动更新；请使用可信来源并核对 SHA-256。
第三方依赖许可证见 _internal/licenses；网页依赖许可证见 _internal/app/web/vendor。

Portable desktop edition (Windows x64)
Extract the entire ZIP and keep _internal beside PersonalAiMemoryOs.exe.
Basic management is self-contained; system WebView2 and .NET Framework 4.8 are required.
User data, configuration and logs stay beside the EXE. AI/RAG are disabled initially.
Use upper-left Settings for AI and RAG profiles. Blank keys retain existing values.
Saving makes no model calls; confirm Restart now or reopen later for model changes to take effect.
The Prompt center manages analysis and QA templates independently; changes apply to new requests immediately.
AI analysis and Draft box are separate pages. Lists offer 10/20/50/100 rows; batches still allow at most 20 sources.
Embedding testing is a separate explicitly confirmed request, and RAG stays off until configured and restarted.
Close the application before copying or backing up its complete directory.
This build is unsigned. It does not install or update itself.
